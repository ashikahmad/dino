Game design and sprites from Chromium’s offline dino game (BSD-3-Clause)

Race friends on your Wi-Fi

  1. On a laptop, open a terminal and run:
    git clone https://github.com/ashikahmad/dino && cd dino && npm install && npm run host
    Needs Node 20.19+ or 22.12+. After pulling updates, run npm install again.
  2. It prints an address and a QR code. Open the address on the laptop and choose Play with friends.
  3. Friends scan the QR code with their phone camera, or type the address. Everyone taps I’m ready, then anyone taps Start race.

Everyone needs to be on the same Wi-Fi. Guest networks often block this.

Your browser may warn that the page is not secure; that is expected on a home network.
